# LizzBot Health — public OAuth branding

Generic homepage and privacy policy for the LizzBot Health Google OAuth consent screen.

This repository contains no health data and no account credentials. It exists so Google Cloud OAuth Branding can link to a public homepage and privacy policy.

Live site: https://lizzbot-lrnm.github.io/lizzbot-health/

To add a Google Search Console URL-prefix verification file, put the `google*.html` file in this directory (the site root), commit, and push to `main`. It will be served at `https://lizzbot-lrnm.github.io/lizzbot-health/<filename>`.
